# Temperature Converter 🌡️

A sleek and responsive web-based Temperature Converter application developed as part of the **Oasis Infobyte Web Development & Designing Internship (Level 1, Task 3)**.

## 🚀 Features
* Convert temperatures seamlessly between **Celsius**, **Fahrenheit**, and **Kelvin**.
* Handles decimal values and negative temperatures accurately.
* Input validation to handle invalid/empty entries gracefully.
* Clean, vintage-inspired card interface design.
* Fully responsive layout tailored for mobile, tablet, and desktop screens.

## 🛠️ Technologies Used
* **HTML5** — Page structure and layout
* **CSS3** — Styling, layout design, typography, and custom color variables
* **JavaScript (ES6)** — Dynamic temperature conversion logic
